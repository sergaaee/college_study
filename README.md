# Учёба: матан · линал · дискра

Личный учебный сайт по трём конспектам из этого репозитория:

| Книга | Файл | Недель |
|---|---|---|
| Матанализ 1 | `Matan1_full.pdf` | 13 |
| Линейная алгебра | `Linal2_full.pdf` | 14 |
| Дискретная математика | `Discrete3_full.pdf` | 13 |

## Запуск

```bash
npm install   # один раз
npm run dev   # откроется http://localhost:5173
```

PDF-книги должны лежать в корне проекта (как сейчас) — сайт открывает их прямо в боковой панели «📖».

## Как устроено обучение

В каждой из 40 недель — шесть этапов:

1. **🌍 Зачем** — цель недели, примеры из жизни, разминка-лаборатория.
2. **📘 Теория** — определения и теоремы с цветными блоками (определение / теорема / приём / ловушка / «на экзамене»), вопросы «проверь себя» и ссылки на страницы книги.
3. **🎛 Лаборатория** — интерактив с ползунками. Метод «**предскажи → покрути → сформулируй вывод**»: сначала выбираете ответ, потом проверяете руками.
4. **✏️ Практика** — задачи уровней A / B / C (нумерация как в задачнике книги). К каждой задаче: пример из жизни, **своя лаборатория с ползунками**, подсказки по одной, ответ, решение, самооценка (✅ сам / 🟡 с подсказкой / ❌ не вышло → в повторение). Ссылки «в задачнике» и «ответ в книге» открывают нужные страницы PDF.
5. **🧠 Закрепление** — мини-тест (с подмешиванием вопросов из прошлых недель), карточки, ловушки недели, термины на русском / English / עברית (из «Терминов недели» конспектов).
6. **🏁 Итог** — чек-лист «что я должен уметь» (из книги), оценка освоения, заметки; «Завершить неделю» ставит карточки в расписание повторений.

Дополнительно:

- **Повторение** — интервальные карточки (1 → 2 → 4 → 8 → 16 → 35 → 70 дней) по всем книгам вперемешку: определения, формулы, термины, ошибочные задачи и вопросы теста. Горячие клавиши: `Space` — показать ответ, `1–4` — оценка.
- **Термины** — 575 терминов с тренажёром (RU → עב, עב → RU, EN ↔ עב). Экзамены по линалу и дискре на иврите.
- **Лаборатории** — галерея всех ползунков без чтения теории.
- **Экзамен** — таймер на 180 минут и пробный экзамен из книги (открывается в панели).
- **⚙ Настройки** — тема, экспорт/импорт прогресса (хранится в `localStorage` браузера).

## Что внутри

```
src/content/{matan,linal,discrete}/wNN.js   контент недели (теория, лаборатории, задачи, тест, карточки)
src/widgets/                                более 50 интерактивных виджетов (графики, матрицы, графы, комбинаторика…)
src/data/bookIndex.json, terms.json         карта страниц книг и термины RU/EN/HE (собраны скриптом из PDF)
scripts/index-books.py                      пересобрать карту страниц и термины из PDF (нужен poppler)
scripts/check-content.mjs                   проверка контента: npm run check
```

Формулы пишутся в LaTeX (`$…$`) и рисуются KaTeX. Контент недели — обычный JS-объект, его легко править и дополнять:
добавьте задачу в `tasks`, вопрос в `quiz` или лабораторию в `labs` (`w:` — имя виджета из `src/widgets/*`).

Задачи взяты из задачников книг (номера сохранены), решения написаны заново; числовые ответы выборочно сверены компьютерной алгеброй и перебором. Если найдёте расхождение — сверяйтесь с ответами в книге («ответ в книге ↗»).
